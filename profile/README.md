## ⭐ À la une : Algèbre linéaire, penser, calculer, interpréter

Un parcours *Computer-Based Maths* avec Python, **gratuit et en ligne**. Python fait le calcul ; vous faites tout le reste : formuler le problème, choisir les outils, critiquer le résultat, l'expliquer.

- **9 modules**, des vecteurs à la décomposition en valeurs singulières
- **3 projets intégrateurs** : recommander des films, mesurer l'influence dans un réseau, reconnaître des chiffres manuscrits
- **52 notebooks Jupyter**, avec exercices, corrigés et bilan de compétences
- environ **70 heures** de travail en autonomie

👉 **[Commencer le parcours](https://liouai-digital-education.github.io/algebre-lineaire-cbm/)** · [Code source](https://github.com/liouai-digital-education/algebre-lineaire-cbm)

## La démarche

Chaque contenu suit la même progression :

1. **Intuition** : une image claire avant toute formule.
2. **Démonstration** : un raisonnement pas à pas, sans affirmation gratuite.
3. **Pratique outillée** : Python, simulations et tableurs transparents.
4. **Mesure** : le modèle est confronté aux données réelles.
